WHAT “ACCEPTED” MEANS

Explicit limits.

The runtime solves a constrained sparse linear system, then independently recomputes its residual using the current matrix and right-hand side. The adjoint uses the same constrained equations. Reused memory proposes a starting correction; classical iterations decide convergence.

A small residual and backward error describe the stored equations. They do not certify physical accuracy or a small solution error in an ill-conditioned system. This editor supports bounded two-dimensional, linear models. Timing here includes assembly, both solves and verification, and is a local observation.
