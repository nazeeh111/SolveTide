# Code, data and dependency licenses

SolveTide's original source is released under the repository [MIT license](../LICENSE). This inventory records the build environment inspected on 29 October 2026. It is not a claim that every upstream binary contains only its top-level project's license.

## Runtime and study dependencies

| Component | Inspected version | License / source | Use |
| --- | --- | --- | --- |
| NumPy | 2.5.4 | [NumPy license](https://github.com/numpy/numpy/blob/main/LICENSE.txt); installed distribution declares `BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0` | Numerical arrays and small dense algebra |
| SciPy | 1.18.1 | [BSD-3-Clause](https://github.com/scipy/scipy/blob/main/LICENSE.txt), with bundled component notices in installed distribution | Sparse matrices, mature solvers, optimization and independent direct checks |
| scikit-fem | 12.0.2 | [BSD-3-Clause](https://raw.githubusercontent.com/kinnala/scikit-fem/master/LICENSE) | Finite-element mesh, forms and assembly |
| PyAMG | 5.3.0 | [MIT](https://raw.githubusercontent.com/pyamg/pyamg/main/LICENSE.txt) | Optional multigrid comparison |
| Matplotlib | 3.11.2 | [Matplotlib license](https://matplotlib.org/stable/project/license.html), based on PSF terms, plus bundled font notices | Optional generation of figures |
| pytest | 9.2.0 | MIT in installed distribution | Development checks |
| build | 1.6.1 | MIT in installed distribution | Packaging |

Dependencies are separately installed packages. SolveTide does not copy their source or package their binaries into its own wheel. Their wheels retain upstream notices, including BLAS and other bundled components. If a future standalone distribution vendors dependencies or fonts, retain all relevant notices from the exact distributed bytes. The package dependency constraints and lock file, when present, govern installation; the table records the environment originally inspected.

No separately billed service or API is used. The editor's assets are local and do not require a font CDN. No third-party dataset or pretrained weights are required. Synthetic systems and trajectories are generated by the repository's assembly and experiment code. Policy coefficients trained from those trajectories are project-generated artifacts under the same MIT terms; their provenance must identify training inputs, split and generation command.

## Referenced methods are not bundled implementations

PETSc, JAX, SOLVAX, G-RANS, SKR and PCGBandit are research/design references, not shipped runtime components. PCGBandit's repository identifies an MIT license, but its OpenFOAM deployment has separate dependencies and terms; no OpenFOAM source or binary is redistributed here. The cited research PDFs are linked, not copied into the release. No license for G-RANS code or weights was inferred from the proceedings abstract. There is no claim of endorsement by upstream authors.

See [research.md](research.md) for attribution, mathematical distinctions and which comparisons were not executed.
