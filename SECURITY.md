# Security

SolveTide is a local numerical research tool. Its editor binds to loopback and does not execute uploaded code. Do not expose it to a public network. Reports about unsafe request handling or data loss can be submitted through the repository's private vulnerability reporting facility when available, or a minimal issue without confidential data.

Numerical residual checks are not safety-critical certification. Malformed, unsupported or failed computations must not expose an accepted current field or gradient.
